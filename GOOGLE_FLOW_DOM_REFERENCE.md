# Google Flow DOM Exact Selectors Reference Guide

This document specifies the exact DOM elements and automation selectors for Google Flow (flow.google.com).

## 1. Settings / Aspect Ratio Button
Google Flow never displays the word `"Settings"` as innerText. It is an icon button at the bottom prompt bar.
- **Selector**: `button[aria-label="Settings trigger"]` or `button.settings-trigger-button`
- **Click Action**:
  ```javascript
  const btn = document.querySelector('button[aria-label="Settings trigger"]');
  if (btn) btn.click();
  ```
- **Fallback / Safe Handling**: If this button is already configured or not found, DO NOT FAIL or stop. Google Flow defaults to 16:9 widescreen or previous session preference automatically. Proceed directly to prompt input.

## 2. Aspect Ratio Menu Item (16:9)
Once Settings trigger is clicked, an overlay menu opens:
- **Selector**:
  ```javascript
  const btn16_9 = Array.from(document.querySelectorAll('button, [role="menuitem"], [role="option"]'))
    .find(b => b.innerText && b.innerText.includes('16:9'));
  if (btn16_9) btn16_9.click();
  ```

## 3. Prompt Input Box
Google Flow uses a `contenteditable` ProseMirror div, NOT a standard `<textarea>` or `<input>`:
- **Selector**: `div.ProseMirror`
- **Input Text Action**:
  ```javascript
  const editor = document.querySelector('.ProseMirror');
  if (editor) {
    editor.focus();
    document.execCommand('selectAll', false, null);
    document.execCommand('delete', false, null);
    document.execCommand('insertText', false, promptText);
    editor.dispatchEvent(new InputEvent('input', { bubbles: true, cancelable: true, inputType: 'insertText', data: ' ' }));
  }
  ```

## 4. Start Generation Button
- **Selector**: `button[aria-label="Start generation"]` or `button.generate-icon-button`
- **Action**:
  ```javascript
  const genBtn = document.querySelector('button[aria-label="Start generation"]');
  if (genBtn && !genBtn.disabled) {
    genBtn.click();
  }
  ```

## 5. Harvest Generated Images
Images generated by Flow have `src` hosted on Google ASB CDN:
- **Selector**: `img[src*="flow.google.com/asb/"]`
